```bash
ln [flags] SOURCE <TARGET>
```

By default, ln will create a hard link. A hard link is indistinguishable from the files original directory entry. Hard-linking a directory is forbidden by the filesystem.
# The flag -s
Generates a symlink

`ln -s SOURCE <TARGET>`
