Hereunder is a list of all the keyboard shortcuts I use regularly

# Text editing
- `cmd + right`: skip to end of line
- `cmd + left`: skip to start of line
- `cmd + down`: skip to end of document
- `cmd + up`: skip to start of document
- `+ shift`: highlight skipped text 

- `opt + right`: skip to next word
- `opt + left`: skip to previous word
- `opt + down`: skip to end of paragraph
- `opt + up`: skip to start of paragraph
- `+ shift`: highlight skipped text 

- `opt + '`: "æ"
- `opt +q`: "œ"

# Utility
- `cmd + shift + z`: redo
- `cmd + space`: spotlight
- `opt + space`: alfred
- `shift + cmd + 3`: capture screen
- `shift + cmd + 4`: screen clipper
- `shift + cmd + 5`: advanced capture options
- `shift + cmd + 6`: capture touch bar
