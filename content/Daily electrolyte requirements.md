# Electrolytes

### **Adult (NICE)** 
- sodium requirement 1mmol/kg/day
- potassium requirement 1mmol/kg/day
- chloride requirement 1mmol/kg/day
- glucose 50-100g/day (_strictly speaking glucose is NOT an electrolyte)_

> [!nota] Most hospital guidelines in New Zealand state that the **maximum rate of potassium infusion is 10mmol/hr**

> [!nota] In routine practice, potassium infusion should generally not exceed 20mEq/hr (20mmol/hr)

Normal saline, and the other common crystalloids, are made up with sodium chloride and the daily requirement for these ions will be covered by maintenance with crystalloid (even D4/5NS1/5 contains enough).

| **Crystalloid** | **Sodium per 1L** | **Chloride per 1L** | **Glucose per 1L** |
| --------------- | ----------------- | ------------------- | ------------------ |
| NS              | 154mmol           | 154mmol             | -                  |
| Hartmann’s      | 131mmol           | 111mmol             | -                  |
| D4/5NS1/5       | 31mmol            | 31mmol              | 222mmol = 40g      |
