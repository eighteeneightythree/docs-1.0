For regular verbs:

| Pronoun               | Inflection (-ar, -er, -ir) |
| --------------------- | -------------------------- |
| Yo                    | -o                         |
| Tú                    | -as, -es                   |
| El, ella, usted       | -a, -e                     |
| Nosotros              | -amos, -emos, -imos        |
| Vosotros              | -áis, -éis, -ís            |
| Ellos, ellas, ustedes | -an, -en                   |
